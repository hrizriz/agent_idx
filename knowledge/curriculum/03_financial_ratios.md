# Rasio Keuangan Inti (IDX)

## Profitabilitas
| Rasio | Rumus ringkas | Baca cepat |
|---|---|---|
| Gross margin | Laba kotor / penjualan | Daya tahan harga vs COGS |
| Operating margin | Laba usaha / penjualan | Efisiensi operasi |
| Net margin | Laba bersih / penjualan | Profit akhir |
| ROE | Laba bersih / ekuitas | Return untuk pemegang saham |
| ROA | Laba bersih / aset | Efisiensi aset |

## Solvabilitas & leverage
| Rasio | Baca cepat |
|---|---|
| DER (Debt/Equity) | Beban utang vs modal sendiri |
| Interest coverage | Kemampuan bayar bunga |
| Current ratio | Likuiditas jangka pendek |

## Khusus perbankan
| Metrik | Arti |
|---|---|
| NIM | Spread bunga (inti profit bank) |
| NPL / LAR | Kualitas aset kredit |
| CoC | Biaya kredit / pencadangan |
| CASA | Porsi dana murah |
| CAR | Kecukupan modal |
| LDR | Penyaluran kredit vs DPK |

## Efisiensi
- **Asset turnover**: penjualan / aset.
- **Inventory days** (dagang/manufaktur): perputaran stok.
- **Cash conversion cycle**: kecepatan putar kas.

## Red flags
- Laba naik tapi arus kas operasi turun tajam.
- Piutang / inventori tumbuh jauh lebih cepat dari penjualan.
- Utang naik untuk menutup operasi, bukan ekspansi produktif.
- Bergantung pada satu pelanggan / komoditas tanpa hedge.

## Cara agent memakai rasio
- Jika user unggah PDF laporan: ekstrak angka, hitung/interpretasi rasio.
- Jika hanya data transaksi: **jangan mengarang** NIM/ROE/NPL; arahkan ke laporan keuangan.
